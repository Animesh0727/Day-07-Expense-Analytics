# Day 07 - Expense Analytics System

## 📌 Project Overview

Expense Analytics System is a Python and SQLite based application that stores and analyzes personal expenses.

The project demonstrates how Python can interact with a SQLite database and use SQL queries to generate useful expense analytics.

## 🚀 Features

- Add new expenses
- Store expenses in SQLite database
- Calculate total expenses
- Calculate average expense
- Analyze expenses category-wise
- Interactive menu system

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- Git & GitHub

## 🧠 SQL Concepts Used

- CREATE TABLE
- INSERT INTO
- SELECT
- SUM()
- AVG()
- GROUP BY
- Parameterized queries
